Resume Match Analyzer - Setup Instructions

Welcome to the Resume Match Analyzer! This application helps you analyze how well your resume matches job descriptions using AI.

Getting Started

1. Local Development

To run this application locally:

  1. Clone this repository
  2. Run npm install to install dependencies
  3. Create a .env file in the root directory with your Cohere API key: 
    VITE_COHERE_API_KEY=your-cohere-api-key-here
  4. Run npm run dev to start the development server

2. Using the Application

  1. Upload your resume (PDF or TXT) or paste the text directly
  2. Paste the job description you're applying for
  3. Click "Analyze My Resume" to get your match analysis
  4. Review the match score, present skills, missing skills, and improvement suggestions

3. Without API Key (Demo Mode)

If you don't have a Cohere API key, the application will run in demo mode with mock data. All functionality is still available for testing.

Note: Your API key is stored in the .env file, which is excluded from the repository via .gitignore. This ensures your API key is never exposed in the codebase.

Deployment

This application can be deployed to any static hosting service. GitHub Pages deployment is configured via GitHub Actions.

Technologies Used

  • React with TypeScript
  • Vite (build tool)
  • Tailwind CSS (styling)
  • Cohere AI API
  • pdf-parse (PDF text extraction)
